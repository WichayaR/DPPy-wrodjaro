# DPPy-wrodjaro
Discovery Piscine: Core Python Programming 42 Bangkok KMITL

This repository contains my ongoing exercises and the Rush00 mini-project from the Discovery Piscine (Core Python Programming) at 42 Bangkok.

## Repository Structure

### 1. Piscine Exercises (`discovery_piscine/`)
Daily Python exercises covering fundamental programming concepts (currently completed up to `cell05`, with remaining cells in progress):
- `cell00`: Basic shell and environment setup
- `cell01`: Variables, basic data types, and string printing
- `cell02`: Conditional statements (`if`, `elif`, `else`) and comparisons
- `cell03`: Loops (`while`, `for`) and basic iterations
- `cell04`: User input handling, type conversion, and number formatting
- `cell05`: Lists, dictionaries, parameters, and array manipulation
- *(Upcoming cells: Functions, modules, and object-oriented basics - Work in Progress)*

### 2. Mini Project - Rush00 (`discovery_piscine/rush/`)
- **Project Name**: 42 Express Bus Ticket Kiosk
- **Description**: A terminal-based self-service bus seat booking application built in a team of two. Users can view the 28-seat bus layout, book VIP or Standard seats, cancel bookings for a refund, view receipt summaries, and filter available seats by zone.
- **Team Members**: `wrodjaro`, `ajommuen`

## How to Run the Mini Project
Navigate to the `rush` folder and run `main.py`:

```bash
cd discovery_piscine/rush
python3 main.py
```
